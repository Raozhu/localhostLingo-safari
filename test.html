4. 特殊文本特征拦截 (Text Pattern Interception)

The extension should smartly ignore pure symbols, URLs, emails, etc.

  • Pure URLs: https://github.com/google/gemini
  • Emails: contact@example.com
  • Numbers/Dates/Currency: 2024-05-20 14:30 PM, $1,234.56, €89.00
  • Short gibberish (<= 2 chars): OK
  • Pure symbols: @#%&*()-+

However, a normal sentence containing a URL like "Visit https://google.com for more info." should be translated.
